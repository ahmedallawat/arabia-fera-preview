# Arabia Fera preview

Preview of the Arabia Fera tours app (sample data, test payments).

- **iPhone**: open https://ahmedallawat.github.io/arabia-fera-preview/ in Safari, then Share › Add to Home Screen.
- **Android app**: download https://ahmedallawat.github.io/arabia-fera-preview/Arabia-Fera-preview.apk and open it to install.
- **Android (web version)**: open the site in Chrome, then ⋮ › Install app.
